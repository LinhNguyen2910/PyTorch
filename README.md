# PyTorch — From Fundamentals to Deep Learning

My personal learning repository for studying and implementing Deep Learning with PyTorch, starting from fundamental concepts and gradually progressing to advanced models and practical applications.

This repository is continuously updated as I learn new concepts, implement tutorials, and build Deep Learning projects.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/LinhNguyen2910/PyTorch.git
cd PyTorch
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run an example

```bash
python Main/AutoGrad.py
```

Some examples may require additional datasets or dependencies.
